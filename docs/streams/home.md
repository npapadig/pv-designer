# Stream: home (αρχική οθόνη)

**Στόχος (Νίκος, 2026-10-22):** όταν ανοίγει η εφαρμογή, εμφανίζεται αρχική οθόνη με τετράγωνα (κάρτες) στη μέση.
- Κάρτα **«Νέο έργο»** → ερώτηση: **«Σε υπάρχον κτίριο»** (πάει στον χάρτη, βήμα «Χώρος», όπως σήμερα) ή
  **«Σε σχέδιο κάτοψης»** (ανοίγει επιλογή αρχείου για upload· η κάτοψη μπαίνει πάνω στον χάρτη ώστε να σχεδιάζει
  τη στέγη/περιοχές πάνω της).
- Από κάτω (ή δίπλα): **τα αποθηκευμένα έργα** ως κάρτες (όνομα, ημερομηνία, kWp αν υπάρχει) → κλικ = άνοιγμα.
  Διαγραφή με επιβεβαίωση.
- Τρόπος να γυρίσεις στην αρχική οθόνη από την εφαρμογή (π.χ. λογότυπο/κουμπί «Αρχική»).

**Κάτοψη (upload):** PNG/JPG (και PDF πρώτη σελίδα μόνο αν γίνεται χωρίς νέα βιβλιοθήκη). Μπαίνει ως ημιδιάφανη
εικόνα πάνω στον χάρτη. Ο χρήστης μπορεί να τη μετακινήσει, να την περιστρέψει, να αλλάξει διαφάνεια, και να ορίσει
**κλίμακα**: δύο κλικ σε δύο σημεία της κάτοψης + «πόσα μέτρα είναι» → η εικόνα παίρνει σωστό μέγεθος. Κλείδωμα
όταν τελειώσει. Αποθηκεύεται με το έργο (η εικόνα σε `data/plans/`, git-ignored, όπως τα έργα).
ΟΧΙ νέες βιβλιοθήκες χωρίς να ρωτηθεί ο Νίκος — προτίμησε δικό σου κώδικα (Leaflet + CSS transform/canvas).

**Αρχεία που ανήκουν στη ροή:** νέα `frontend/home.js`, `frontend/plan.js`, `frontend/home.css` (link στο index.html),
`frontend/index.html` (μόνο η αρχική οθόνη + κουτί κάτοψης), `frontend/app.js` ΜΟΝΟ το τμήμα «Projects»
(γρ. ~596-710) και μικρά hooks στην εκκίνηση, `backend/storage.py`, `backend/main.py` (ΜΟΝΟ νέα routes στο τέλος,
για κατόψεις/λίστα έργων), νέα tests. Μην αγγίξεις `style.css`, το τμήμα «Map» του app.js (άλλη ροή) ή τον υπολογισμό.

**Βήματα (ένα commit το καθένα):** 1) αρχική οθόνη + λίστα έργων + επιστροφή, 2) Νέο έργο → επιλογή κτίριο/κάτοψη,
3) upload κάτοψης + τοποθέτηση/περιστροφή/κλίμακα/διαφάνεια, 4) αποθήκευση/φόρτωση κάτοψης με το έργο.
Ωραία, καθαρή εμφάνιση που ταιριάζει με το υπάρχον θέμα (σκούρο/φωτεινό, `ui.js`). Κείμενα στα ελληνικά, απλά.

**Έλεγχοι:** `python -m pytest` όλα περνάνε, baseline ίδιο. Browser σε θύρα 8030 (όχι 8000), σκούρο και φωτεινό θέμα,
και στενή οθόνη. Μην αλλάξεις VERSION/CHANGELOG/HANDOFF ή line endings.
