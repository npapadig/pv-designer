# Stream: pdf (εικόνα χάρτη στην αναφορά)

**Πρόβλημα (Νίκος, 2026-10-22):** στο PDF η εικόνα του χάρτη/στέγης βγαίνει «πάρα πολύ περίεργη και κακοβγαλμένη
τελείως», ενώ στον χάρτη της εφαρμογής φαίνεται κανονικά.

**Στόχος:** η εικόνα στο PDF να είναι καθαρή, σωστά κεντραρισμένη/ζουμαρισμένη, με τον ίδιο υπόβαθρο χάρτη που
βλέπει ο χρήστης (Esri / Clarity / Κτηματολόγιο / Google αν έχει κλειδί), σωστά πάνελ/περιοχές/εμπόδια πάνω της,
χωρίς παραμορφώσεις (λόγος διαστάσεων), σε καλή ανάλυση.

**Αρχεία:** `backend/mapimage.py`, `backend/report.py` (μόνο ό,τι αφορά την εικόνα), `frontend/app.js` ΜΟΝΟ το
τμήμα «PDF report» (γρ. ~562-595) αν χρειάζεται να σταλεί ποιος χάρτης/zoom είναι ενεργός, tests.

**Βήματα:** 1) Αναπαραγωγή: φτιάξε έργο (π.χ. από `tests/baseline/projects.json`) και βγάλε PDF· δες την εικόνα
(μετατροπή σελίδας σε PNG ή εξαγωγή της εικόνας) και βρες τι φταίει (λάθος zoom/πλακίδια, παραμόρφωση, λάθος
μετατροπή συντεταγμένων, χαμηλή ανάλυση, άλλος χάρτης κ.λπ.). 2) Διόρθωση. 3) Τεστ που ελέγχει διαστάσεις/αναλογία
και ότι τα σχήματα πέφτουν μέσα στην εικόνα. Αν χρειαστεί να δεις τι είδε ο Νίκος, ζήτα του με απλό κείμενο να
βάλει screenshot στο `C:\pv-designer\_inputs\tests\`.

**Έλεγχοι:** `python -m pytest` όλα, baseline ίδιο. Δοκιμή με πραγματικό PDF από τον browser σε θύρα 8040.
Μην αλλάξεις VERSION/CHANGELOG/HANDOFF ή line endings.
