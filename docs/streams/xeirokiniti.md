# Ροή «xeirokiniti» — χειροκίνητη μετακίνηση πάνελ + έλεγχος περιορισμών (αίτημα Νίκου 2026-10-26)

**Στόχος:** ο χρήστης πιάνει με το ποντίκι τα πάνελ της τοποθέτησης και τα μετακινεί όπως θέλει· στο τέλος η εφαρμογή
επισημαίνει ποιους περιορισμούς καταπατά κάθε πάνελ (εκτός περιγράμματος, κοντά σε εμπόδιο/διαχωρισμό, επικάλυψη, σκίαση).

**Αρχεία που κατέχει:** `backend/manual.py` (νέο), endpoint `/api/layout/check` στο `backend/main.py`, μικρή εξαγωγή
βοηθητικής στο `backend/layout.py`, `frontend/manual.js` + `manual.css` (νέα), λίγες γραμμές στο `frontend/app.js` και
`index.html` (κουμπιά στο βήμα «Πάνελ»), `frontend/lang/en.js`, `tests/test_manual.py`. ΔΕΝ αγγίζει VERSION/CHANGELOG/HANDOFF, hero.js/css.

**Σχεδιασμός:** τα πάνελ είναι ήδη πολύγωνα στο `panelsLayer`· οι υπολογισμοί (σκίαση, παραγωγή, ηλεκτρολογικά, αποθήκευση)
διαβάζουν από εκεί, άρα η χειροκίνητη διάταξη περνά αυτόματα σε αυτούς. Το drag δουλεύει σε lat/lng (ανεξάρτητο από περιστροφή χάρτη).
Κωδικοί παραβίασης: `outside` (εκτός περιγράμματος), `edge` (κοντά στο περίγραμμα), `ridge` (κοντά σε διαχωρισμό πλευρών),
`obstacle` (κοντά/πάνω σε εμπόδιο), `overlap` (επικάλυψη πάνελ), `shade` (σκίαση πάνω από το όριο).

## Αριθμημένα βήματα
1. Backend: `backend/manual.py` + `POST /api/layout/check` (παραβιάσεις ανά πάνελ + σε ποια περιοχή/πλευρά ανήκει)· τεστ.
2. Frontend: λειτουργία «Μετακίνηση πάνελ» (επιλογή, ομάδα με Shift/Ctrl, drag, προαιρετικό snap), ενημέρωση `panel_face`.
3. Επισήμανση: κόκκινο περίγραμμα + λίστα παραβάσεων στο UI (κλικ → εστίαση), κείμενα EL+EN.
4. Αποθήκευση/φόρτωση χειροκίνητης διάταξης (`layout.manual`), επανέλεγχος στη φόρτωση, προειδοποίηση πριν ξανατοποθετηθούν αυτόματα.
5. Δοκιμή στον browser (και με περιστροφή χάρτη), τελικά τεστ, αναφορά.
