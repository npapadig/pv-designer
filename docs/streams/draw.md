# Stream: draw (σχεδίαση στον χάρτη)

**Στόχος (Νίκος, 2026-10-22):**
1. Όταν σχεδιάζεις πολύγωνο (και μετά), να φαίνονται **τα μέτρα κάθε πλευράς** πάνω στη γραμμή, για έλεγχο.
2. **Ωραιότερες γραμμές**: το περίγραμμα κατά τη σχεδίαση και μετά (χρώματα, πάχος, κορυφές/λαβές, γέμισμα), ίδιο
   ύφος με το θέμα της εφαρμογής.
3. **Ωραιότερα πάνελ** στην τοποθέτηση (π.χ. σκούρο μπλε πάνελ με λεπτό πλαίσιο/κελιά, καθαρό ύφος).
4. **Επεξεργασία πολυγώνου** μετά τη σχεδίαση: μετακίνηση κορυφών, προσθήκη/αφαίρεση κορυφής, μεγάλωμα/μίκρεμα
   (π.χ. «σπρώξε» μια πλευρά ή γράψε νέο μήκος πλευράς), εύκολα και φανερά (όχι κρυμμένο στο εργαλείο του Leaflet.draw).
5. **Πυξίδα** στον χάρτη (Β, Ν, Α, Δ), καθαρή, σε μια γωνία.

**Αρχεία:** νέα `frontend/draw.js`, `frontend/draw.css` (link στο index.html), `frontend/app.js` ΜΟΝΟ το τμήμα
«Map» (γρ. ~19-168) και τα στυλ πάνελ (`addPanel`/`colorPanels`) αν χρειάζεται, `frontend/index.html` ελάχιστα.
Μην αγγίξεις `nudge.js`/`faces.js` εκτός από ελάχιστο hook, ούτε `style.css` (άλλες ροές). Καμία νέα βιβλιοθήκη
χωρίς ερώτηση στον Νίκο.

επεξεργασία, nudge και πλευρές στέγης να δουλεύουν ακόμα, σκούρο/φωτεινό θέμα. Ένα commit ανά βήμα.
