# Stream: voitheia (συννεφάκια βοήθειας + «Περισσότερα»)

**Στόχος (Νίκος, 2026-10-22):** όταν το ποντίκι μένει ~1 δευτερόλεπτο πάνω σε μια επιλογή (κουμπί, πεδίο, βήμα,
κάρτα), εμφανίζεται ένα μικρό «συννεφάκι» με 1-2 γραμμές για το τι κάνει. Μέσα στο συννεφάκι υπάρχει «Περισσότερα…»:
ανοίγει ένα μεγαλύτερο πλαίσιο μέσα στην εφαρμογή με (α) αναλυτική περιγραφή, (β) γιατί μπορεί να το θέλει κάποιος /
γιατί είναι χρήσιμο, (γ) ένα παράδειγμα («π.χ. το χρειάζεσαι όταν…»). Απλά ελληνικά για μη τεχνικό χρήστη.

**Αρχεία (μόνο αυτά):** νέα `frontend/help.js`, `frontend/help.css`, `frontend/helptexts.js` (τα κείμενα, σε ΕΝΑ
σημείο, κλειδί = id); στο `frontend/index.html` ΜΟΝΟ τα `<script>`/`<link>` tags. ΜΗΝ αλλάζεις άλλα αρχεία: τρέχουν
παράλληλα οι ροές sxedio (σχεδίαση), arxi (αρχική/launcher), glossa (μετάφραση).

**Πώς δένει με τα στοιχεία χωρίς να αγγίζει τα αρχεία των άλλων:** το `helptexts.js` έχει εγγραφές με επιλογέα
(CSS selector, π.χ. `#btnSearch`, `#rail a[data-step=secPanels]`, `[data-help=draw-undo]`) → κείμενα. Το `help.js`
βρίσκει τα στοιχεία με event delegation (`mouseover` στο document, `closest`) — έτσι δουλεύει και για στοιχεία που
δημιουργούνται αργότερα. Η ροή sxedio βάζει `data-help="..."` στα νέα της κουμπιά και γράφει τα id στο
`docs/streams/sxedio.md` (στο τέλος)· πρόσθεσε κείμενα και γι' αυτά όταν εμφανιστούν (ή με γενικά id από τώρα:
draw-select, draw-move, draw-copy, draw-paste, draw-delete, draw-undo, draw-redo, draw-ruler, draw-tree, draw-area,
draw-obstacle). Τα υπάρχοντα `title=` μην τα σβήνεις — απλώς κρύψε το native tooltip όσο δείχνεις το δικό σου
(π.χ. μετακίνησέ το προσωρινά σε `data-title`, και επανάφερέ το).

**Βήματα (ένα commit ανά βήμα):**

   να προλαβαίνει να πατήσει «Περισσότερα…»), θέση που δεν βγαίνει έξω από την οθόνη, σκούρο/φωτεινό θέμα,
   πληκτρολόγιο (focus δείχνει το συννεφάκι, Esc κλείνει). Πλαίσιο «Περισσότερα» με τρεις ενότητες
