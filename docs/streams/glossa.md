# Stream: glossa (Ελληνικά / Αγγλικά σε εφαρμογή + PDF)

**Στόχος (Νίκος, 2026-10-22, απόφαση 1α):** επιλογή γλώσσας Ελληνικά / Αγγλικά στην αρχική οθόνη· στα αγγλικά
αλλάζει ΟΛΗ η εφαρμογή ΚΑΙ η αναφορά PDF. Η επιλογή θυμάται (localStorage, με try/catch) και φαίνεται και στο header.

**Γιατί έτσι (παράλληλη δουλειά):** τρέχουν μαζί οι ροές sxedio, arxi, voitheia που αλλάζουν και γράφουν νέα ελληνικά
κείμενα. Για να μη συγκρούεσαι μαζί τους, ΜΗΝ ξαναγράψεις τα αρχεία τους με κλειδιά μετάφρασης. Αντί γι' αυτό:
- `frontend/i18n.js`: λεξικό **ελληνικό κείμενο → αγγλικό** (`frontend/lang/en.js`) και μεταφραστής που περνά τα text
  nodes και τα attributes `title`, `placeholder`, `aria-label`, `value` κουμπιών, με `MutationObserver` ώστε να
  πιάνει και ό,τι δημιουργείται δυναμικά (toasts, κάρτες, popups του Leaflet, βοήθεια). Για κείμενα με αριθμούς
  (π.χ. «3 περιοχή(ές), 1 εμπόδιο(α).», «Εμπόδιο 1,5 m») κανόνες με regex στο ίδιο λεξικό.
- Επίσης `window.t(el_text)` για τα `confirm()`/`alert()`/`toast()` — μπορείς να το καλέσεις μόνο μέσα από
  `i18n.js` τυλίγοντας τα `window.confirm/alert` (όχι αλλαγές στα αρχεία των άλλων). Τοπικές μορφές αριθμών/ημερομηνιών
  (`el-GR` → `en-GB`) όπου γίνεται χωρίς να αγγίξεις τα άλλα αρχεία· αλλιώς σημείωσέ τα για το τέλος.
- Κουμπί γλώσσας (ΕΛ / EN): το ενθέτει το `i18n.js` στην αρχική οθόνη και στο header (όχι αλλαγή στο `home.js`).
- Το λεξικό το γεμίζεις από τα κείμενα του `main` τώρα· στο τέλος (όταν γίνουν merge οι άλλες ροές) ένα βήμα
  «συμπλήρωση» για τα νέα κείμενα. Ένα script/τεστ που βρίσκει ελληνικά κείμενα στα frontend αρχεία χωρίς μετάφραση
  βοηθά πολύ σε αυτό.

**Αρχεία (μόνο αυτά):** νέα `frontend/i18n.js`, `frontend/lang/en.js`, `frontend/i18n.css` αν χρειάζεται; στο
`frontend/index.html` ΜΟΝΟ τα `<script>`/`<link>` tags (το i18n.js να φορτώνει πρώτο ή με MutationObserver από
νωρίς); `backend/report.py` και `backend/i18n.py` (νέο) για το PDF; στο `backend/main.py` ΜΟΝΟ το πέρασμα της γλώσσας
στο endpoint της αναφοράς (π.χ. `lang` στο σώμα του αιτήματος· στο `app.js` «PDF report» ΜΙΑ γραμμή για να στέλνει
`lang`). Νέα τεστ.

**Βήματα (ένα commit ανά βήμα):**
1. PDF στα αγγλικά: `report.py` με κείμενα από `backend/i18n.py` (el/en), `lang` στο αίτημα, προεπιλογή `el` ώστε
   οι υπάρχουσες αναφορές να μένουν ΙΔΙΕΣ. Τεστ: el = όπως πριν, en = χωρίς ελληνικούς χαρακτήρες στα σταθερά κείμενα.

3. Συμπλήρωση μετά τα merge των άλλων ροών (ο συντονιστής θα σου πει πότε) + τεστ/script «ελληνικά χωρίς μετάφραση».
