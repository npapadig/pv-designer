# Stream: arxi (νέο έργο, τύπος στέγης, Google, αναζήτηση, εκκίνηση)

**Στόχος (Νίκος, 2026-10-22, δες PLAN.md «Γύρος αλλαγών»):** καθαρότερη αρχή εργασίας. Ο Νίκος δεν είναι τεχνικός:
όλα τα κείμενα στα ελληνικά, απλά· τα μηνύματα του launcher σε greeklish (το cmd.exe χαλάει τα ελληνικά).

**Αρχεία (μόνο αυτά):** `frontend/home.js`, `frontend/home.css`, `frontend/plan.js`, `frontend/faces.js`;
`frontend/app.js` ΜΟΝΟ τα τμήματα «Search» και «Google satellite», και στο «Projects» ΜΟΝΟ γραμμές για τα νέα πεδία
τύπου έργου/στέγης; `frontend/index.html` ΜΟΝΟ η αρχική οθόνη (home), η γραμμή αναζήτησης, `#planBox`, `#facesBox`,
`#googleBox` (+ script/link tags); νέο `frontend/search.js` αν βοηθά; `start_windows.bat`, `start_mac_linux.sh`
(CRLF στο .bat! μην βασίζεσαι σε `if errorlevel` για τον Python Install Manager — δες CLAUDE.md, docs/ARCHITECTURE.md);
νέο `backend/lifecycle.py` + ΕΛΑΧΙΣΤΕΣ γραμμές στο `backend/main.py`; `backend/settings.py` αν χρειάζεται.
ΜΗΝ αγγίξεις `draw.js`, `nudge.js`, το τμήμα «Map» του app.js, εμπόδια/χώρους (ροή sxedio), `ui.js`/βοήθεια
(ροή voitheia), μετάφραση (ροή glossa). Τρέχουν παράλληλα άλλες 3 ροές.

**Βήματα (ένα commit ανά βήμα):**
1. **Νέο έργο:** «Υπάρχον κτίριο» → ΔΕΝ ρωτά για κάτοψη (πάει στον χάρτη/αναζήτηση). «Νέο κτίριο» → ΠΡΩΤΑ πού θα
   μπει (αναζήτηση/κλικ στον χάρτη), ΜΕΤΑ προτείνει ανέβασμα κάτοψης. Νέα τρίτη επιλογή **«Πάρκο σε χωράφι»**:
   προς το παρόν απλή μορφή (απόφαση Νίκου: λεπτομέρειες αργότερα) — πάει στον χάρτη, έδαφος επίπεδο, οι υπάρχουσες
   προτάσεις διάταξης με βάσεις· αποθηκεύεται ο τύπος (`project_type`: existing/new/park).
2. **Επίπεδη ή κεκλιμένη:** για κτίριο, ερώτηση στην αρχή «Επίπεδη ταράτσα (0°)» / «Κεκλιμένη στέγη». Επίπεδη →
   το `#facesBox` (πλευρές/μοίρες) ΚΡΥΒΕΤΑΙ. Κεκλιμένη → φαίνεται. Αποθηκεύεται (`roof_type`: flat/pitched)· αλλάζει
   και αργότερα (μικρός διακόπτης στο βήμα «Χώρος»). Παλιά έργα: pitched αν έχουν πλευρές, αλλιώς flat. Πάρκο = flat.
3. **Google:** σβήσε το κουτί «Χάρτης Google (προαιρετικό)» από αριστερά. Αν υπάρχει αποθηκευμένο κλειδί, ο χάρτης
   Google ανοίγει μόνος του ως προεπιλογή (χωρίς ερώτηση). Το μενού χαρτών πάνω δεξιά μένει όπως είναι· ΜΟΝΟ αν δεν
   υπάρχει κλειδί (νέα εγκατάσταση), βάλε εκεί ένα μικρό διακριτικό «Κλειδί Google…» για να το βάλει κάποιος.
4. **Αναζήτηση με προτάσεις (Νίκος 4α, δωρεάν):** καθώς γράφεις, λίστα προτάσεων από το Photon
   (`https://photon.komoot.io/api/?q=...` με bias στο κέντρο του χάρτη / Ελλάδα), debounce ~350 ms, από 3 γράμματα,
   βελάκια + Enter, κλικ. Το Nominatim ΔΕΝ επιτρέπει autocomplete — μένει μόνο για το κουμπί αναζήτησης.
5. **Εκκίνηση (T01):** διπλό κλικ → ανοίγει ΚΑΤΕΥΘΕΙΑΝ ο browser, χωρίς μαύρο παράθυρο που μένει (π.χ. server με
   `pythonw`/κρυφά, το .bat κλείνει μόνο του· στην πρώτη εγκατάσταση/ενημέρωση το παράθυρο μπορεί να φανεί γιατί
   γράφει πρόοδο). Ο browser ανοίγει ΜΟΝΟ όταν ο server απαντά (διορθώνει το «Not found»). Η εφαρμογή σταματά όταν
   κλείσει ο browser με το Χ: η σελίδα στέλνει heartbeat + `sendBeacon` στο `pagehide`· ο server σβήνει ~10 s μετά
   το τελευταίο «bye» χωρίς νέο «hello» (το refresh δεν τον σβήνει), και ως δίχτυ ασφαλείας μετά από ~3 λεπτά χωρίς
   heartbeat (οι κρυφές καρτέλες του Chrome στέλνουν σπάνια). Αν ο server τρέχει ήδη, απλώς ανοίγει ο browser.
   Το `update.ps1` να συνεχίσει να δουλεύει. Ενημέρωσε το `docs/ARCHITECTURE.md` (launcher).
   Γράψε στο τέλος αυτού του αρχείου 2-3 γραμμές «τι αλλάζει για τον Νίκο».
