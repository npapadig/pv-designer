1. Χάρτης Google: στο Google Cloud βεβαιώσου ότι το "Map Tiles API" είναι Enabled,
   ότι το κλειδί έχει περιορισμό "Map Tiles API" (API restrictions) και όριο 3000 την ημέρα (Quotas).
2. Στην εφαρμογή: βήμα "Χώρος" -> "Χάρτης Google" -> κόλλησε το κλειδί -> Αποθήκευση. Πες μου τι γράφει.
3. Σύνδεση στο GitHub (μία φορά): άνοιξε PowerShell, γράψε  cd C:\pv-designer  και μετά  git push origin main
   Θα ανοίξει παράθυρο σύνδεσης: συνδέσου με τον λογαριασμό npapadig. Πες μου αν έγραψε "main -> main".
4. Δοκίμασε τα τεστ του αρχείου docs\TESTS_FOR_ME.txt και γράψε δίπλα OK / ΠΡΟΒΛΗΜΑ / ΙΔΕΑ.
